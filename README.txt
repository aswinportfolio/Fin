AI Finance Autopilot - installable app (PWA)

1. Put all files in this folder on any HTTPS host. Free options:
   - Netlify: drag this folder onto app.netlify.com/drop
   - GitHub Pages or Cloudflare Pages
2. Open the hosted link on your phone.
   - Android (Chrome): menu > Install app
   - iPhone (Safari): Share > Add to Home Screen
3. It opens full screen like an app and works offline after the first visit.

For a Play Store APK, paste your hosted link into pwabuilder.com and download the Android package.
Note: portal connections and prices are demo data. Real bank, broker or fund connections need each provider's official API.
